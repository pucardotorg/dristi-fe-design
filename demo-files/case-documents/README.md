# Demo case documents

Twenty sample complaints for the AI-assisted bulk upload (**Bulk filing › Upload case
documents**), one Word file per case. Regenerate with `npm run demo:docs`; dates are set
from the day they are made.

What each one shows on review:

- `TCL-AHD-PL-2001`: headed sections, every field labelled
- `TCL-AHD-PL-2002`: headed sections, every field labelled
- `TCL-AHD-BL-2003`: details laid out in tables
- `TCL-AHD-PL-2004`: The cheque details are given in prose; AI reads them by pattern and marks them to check.
- `TCL-AHD-TL-2005`: Two accused, joint account holders.
- `TCL-AHD-PL-2006`: Loose wording: 'Insufficient funds' and 'RPAD', read as the court's options and marked to check.
- `TCL-AHD-BL-2007`: Two cheques on one complaint.
- `TCL-AHD-PL-2008`: headed sections, every field labelled
- `TCL-AHD-TL-2009`: headed sections, every field labelled
- `TCL-AHD-PL-2010`: Part payment after the notice.
- `TCL-AHD-BL-2011`: details laid out in tables
- `TCL-AHD-PL-2012`: The accused's pincode is missing.
- `TCL-AHD-TL-2013`: cheque details in prose, read by pattern and marked to check
- `TCL-AHD-PL-2014`: headed sections, every field labelled
